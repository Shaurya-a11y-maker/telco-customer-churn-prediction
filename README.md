# Predictive Customer Churn Model (ConnectTel)
A machine learning project that predicts which telecom customers are likely to churn and explains why using SHAP.

- Data: Telco Customer Churn (Kaggle), 7,043 customers
- Models: Logistic Regression, Random Forest, XGBoost (tuned with GridSearchCV)
- Final model: tuned XGBoost (AUC 0.845, recall 0.805)
- Main drivers of churn: month-to-month contract, short tenure, Fiber optic internet
- Notebook: Shaurya_Chadha_Customer_Churn_Model.ipynb
